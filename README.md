# Die Welt der Schokolade

## Beschreibung

Diese Website wurde im Rahmen des SWP1-Unterrichts erstellt.
Sie stellt verschiedene Schokoladensorten vor und dient als
Übung für HTML, Git und GitHub Pages.

## Lokale Verwendung

Das Repository herunterladen oder klonen.
Anschließend die Datei index.html in einem Webbrowser öffnen.
